# 미르스타푸드 ERP — 작업 범위 및 보호 규칙

- 이 프로젝트는 `/erp/` 아래의 ChatGPT 제작 ERP에 한정한다.
- 피클(Pickle)이 제작한 ERP는 사용자 본인이 별도로 명시적으로 요청하지 않는 한 영구적으로 수정 금지한다. 저장소 루트 ERP, 공유 파일, 피클의 배포 설정과 데이터베이스를 변경하거나 삭제하지 않는다.
- 변경 전 최신 소스와 브랜치를 확인하고, 운영 반영 전 PC·모바일 브라우저에서 기능을 검증한다.
- 실제 회사 재고 및 거래 데이터를 테스트 목적으로 변경하지 않는다. 테스트는 격리된 가상 데이터로 수행한다.
- 운영 반영 후 공개 배포 파일을 검증본과 대조하고, 완료하지 못한 검사는 명확히 보고한다.
