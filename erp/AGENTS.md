# 미르스타푸드 ERP — 작업 범위 및 보호 규칙

- 이 프로젝트는 `/erp/` 아래의 ChatGPT 제작 ERP에 한정한다.
- 피클(Pickle)이 제작한 ERP는 사용자 본인이 별도로 명시적으로 요청하지 않는 한 영구적으로 수정 금지한다. 저장소 루트 ERP, 공유 파일, 피클의 배포 설정과 데이터베이스를 변경하거나 삭제하지 않는다.
- 변경 전 최신 소스와 브랜치를 확인하고, 운영 반영 전 PC·모바일 브라우저에서 기능을 검증한다.
- 실제 회사 재고 및 거래 데이터를 테스트 목적으로 변경하지 않는다. 테스트는 격리된 가상 데이터로 수행한다.
- 운영 반영 후 공개 배포 파일을 검증본과 대조하고, 완료하지 못한 검사는 명확히 보고한다.

## 공통 데이터 처리 원칙 (사용자 승인 2026-11-28)
- ChatGPT ERP의 운영 화면(`erp-next/operating.html` 포함)에만 적용. 피클 제작 ERP는 변경 금지.
- 업무일과 실제 등록·수정 시각을 분리한다. 등록자/수정자는 확인된 계정 기준으로 기록하고, 과거 기록에서 알 수 없는 시간이나 계정은 추정하지 않는다.
- 입고·출고·이동의 `_seq`는 전체 공통 등록 순번이다. 신규 등록 시 기존 전체의 최댓값 다음 번호를 사용하고 수정 시 유지한다. 최근 작업은 합친 내역을 순번 내림차순으로 정렬한 다음 최신 4건을 표시한다.
- 입고·출고·이동 및 통합 내역의 기본 정렬은 업무일 최신순, 동일 날짜는 등록 순번 최신순. 변경이력은 기록 추가 순서의 역순. 재고 정렬과 재고 재생 계산 순서는 별도 유지한다.
- PC·모바일·외부 AI 입력에서 데이터 처리 규칙은 동일하다. 외부 입력도 기존 인증 및 저장 경로와 공통 순번을 사용한다. 신규 기능은 등록·수정 메타데이터와 화면별 정렬을 설계·검증한 후 배포한다.
- 순서 검증은 서로 다른 작업 종류, 과거 업무일의 신규 등록, 동일 업무일, 수정 시 최초 등록 정보 유지 및 기존 재고 불변을 포함한다. 실제 거래 데이터는 테스트용으로 변경하지 않는다.
