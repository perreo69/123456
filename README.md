# 통합 ERP — 🥩 원료육 · 📦 완제품 · 💰 회계

냉동고·냉장고 원료육 재고, 완제품 재고와 입출고, 매입·매출·수금·경비 회계를
**한 화면에서 모드만 바꿔** 쓰는 웹앱입니다.
Supabase 로그인으로 들어가고 데이터는 Supabase에 저장되므로 PC·폰 어디서 열어도 같은 내용이 보입니다.

- **모드**: `🥩 원료육 ERP` · `📦 완제품 ERP` · `💰 회계 ERP` (상단 버튼으로 전환)
- **폰 최적화**: 768px 이하에서는 모드 버튼이 폭을 꽉 채우고, 요약 카드는 2열,
  화면 아래 **퀵 바**(`📝 입력하기` / `📋 목록보기`)로 입력과 표를 바로 오갑니다.
  홈 화면에 추가하면 주소창 없이 앱처럼 열립니다(웹앱 메타 태그 포함).
- **2개월 달력**: 모든 모드의 `📅 기간선택`에서 이카운트와 같은 2개월 달력이 열립니다.
  폰에서는 두 달력이 **위/아래 1열**로 깔끔하게 놓입니다.
- **열 너비**: 모든 표에서 머리글 오른쪽 경계를 **드래그**해 늘리고 줄이고,
  **더블클릭**하면 내용에 맞춰집니다. 바꾼 너비는 브라우저(localStorage)에 저장되고
  `↔ 열 너비 초기화`로 되돌립니다.

## 1. 🥩 원료육 ERP

기존 원료육 ERP 기능을 **그대로** 유지했습니다. (원료육 화면에는 회계 항목을 넣지 않았습니다)

- 모드: `📥 입고` · `🧊→❄️ 해동` · `❄️→🧊 재냉동` · `📤 출고(현장/업체/택배/기타)`
- 표: 냉동고 재고 · 냉장고 재고 · 입출고 내역 — 머리글 클릭 정렬, `▾` 값 필터
- `브랜드` 열, `입고단가(원/kg)`·`출고단가(원/kg)` 분리 표시
- `📅 기간선택` 2개월 달력 + `🔍 검색`, 사방넷/경리나라 양식 다운로드
- 로트 선택 행은 파란 배경으로 표시되며, 행 모양(높이·칸)은 다른 행과 똑같습니다.

## 2. 📦 완제품 ERP

- **요약 카드**: 완제품 총재고 · 보유 품목 · 총 재고금액(입고단가 기준) · 오늘 입출고 · 단가 미입력
- **대분류 필터**: `전체` `완제품` `소스` `부재료` `향신료` `야채류` + `＋ 직접입력`(직접 만든 분류는 저장됨)
- **왼쪽 입력**: `📥 입고` / `📤 출고` 탭, `＋ 새 상품 등록`, 상품코드·상품명으로 찾기
  - **`규격`**·`단위`·`입고단가`·`출고단가`를 상품마다 관리하고, 입출고 할 때 그대로 따라갑니다.
  - 출고는 재고보다 많으면 막고, 필요하면 `재고보다 많이 출고 허용`을 켜 마이너스 재고로 기록합니다.
- **오른쪽 탭 3개**: `📦 재고현황` · `📋 입출고 이력` · `💰 단가 관리`
  - 재고현황: 대분류 · 상품코드 · 상품명 · **규격** · 단위 · 재고 · 입고단가 · 출고단가 · **재고금액** · 유통기한
  - 이력: 날짜 · 구분 · 코드 · 상품명 · 규격 · 단위 · 수량 · 입고/출고단가 · 금액 · 소비기한 · 거래처·비고 · 작업자
- **엑셀**
  - `⬇ 입출고 양식` — 날짜·구분·상품코드·상품명·**규격**·단위·수량·입고단가·출고단가·소비기한·거래처·비고
  - `⬆ 입출고 엑셀` — `.xlsx` / `.csv` 를 그대로 올립니다. 코드가 비면 상품명으로 찾습니다.
  - `⬇ 단가표 양식` / `⬆ 단가표 엑셀` — 상품코드·상품명·**규격**·단위·입고단가·출고단가
  - `⬇ 완제품 재고 엑셀` · `⬇ 입출고 이력 엑셀`
- 외부 라이브러리(CDN) 없이 **순수 JS**로 엑셀을 읽고 씁니다(압축 해제까지 직접 구현).
  인터넷이 막힌 환경에서도 업로드·다운로드가 됩니다.

## 3. 💰 회계 ERP

원료육·완제품과 분리된 전용 회계 모듈입니다.

- **요약 카드 6개**: 총 받을 돈(외상매출금) · 총 줄 돈(외상매입금) ·
  세금계산서 미발행/미수령 · 이번 달 매출 · 이번 달 매입·경비 · 예상 순이익
- **탭 4개**
  1. `📋 매입·매출 전표`
     - 직접 추가·수정·삭제, **면세/과세(부가세 10%) 자동 계산**, `부가세 포함 금액`으로 입력하면 거꾸로 계산
     - **세금계산서 발행/수령 상태** 버튼 한 번으로 토글
     - **`⚡ 입출고 일괄 반영`**: 기간 안의 원료육 입고·업체출고, 완제품 입출고 중
       금액이 있는 건을 체크해 **클릭 한 번으로 전표로** 넘깁니다.
       원료육은 면세, 완제품은 과세가 기본(전부 면세/과세로 바꿀 수 있음). 같은 이력은 두 번 들어가지 않습니다.
  2. `🏢 거래처별 원장`
     - 거래처별 총 매출·총 수금·**남은 미수금**, 총 매입·총 지급·**남은 미지급금**, 받을−줄
     - `수금`·`지급`을 등록하면 잔액이 바로 차감되고, `내역`에서 그동안의 입금·출금을 보고 지울 수 있습니다.
  3. `💳 일반 경비·자금`
     - 택배비·부자재·전기세·임대료·급여·식대·차량유지비 등 재고 외 지출/수입
     - 간편 입력 또는 **통장·카드 엑셀 업로드**(날짜·적요·거래처·출금·입금 → 경비/수입 자동 구분)
  4. `📊 월별 손익`
     - 월별 매출 − 매입원가 − 일반경비 = **순이익** 표와 합계, 엑셀 다운로드
- 회계 표에도 **열 너비 드래그 + 2개월 달력 + 검색 버튼**이 똑같이 적용됩니다.
- 순이익은 부가세를 빼고 **공급가액** 기준으로 계산합니다.

## 설치 1단계 — Supabase에 표·함수·초기 데이터 넣기

**처음 설치하는 경우** — `downloads/supabase_setup.sql` (또는 같은 내용의 `.txt`)을 실행합니다.

1. <https://supabase.com/dashboard> → 프로젝트(`gzufnyglmvgzqltepock`) 선택
2. 왼쪽 메뉴 **SQL Editor** → **New query**
3. `supabase_setup.sql` 내용 **전체**를 복사해 붙여넣고 **Run**
4. 맨 아래 결과가 아래처럼 나오면 성공

| 로트수 | 냉동총재고kg | 냉장총재고kg | 입출고이력수 | 완제품품목수 | 회계전표수 |
|---|---|---|---|---|---|
| 177 | 7216.37 | 3598.40 | 607 | 0 | 0 |

완제품·회계 표는 **깨끗한 상태(0건)** 로 시작합니다. 예시 상품이나 사방넷 데이터는 넣지 않습니다.

**이미 쓰고 있는 DB를 그대로 업그레이드하는 경우** — `downloads/supabase_migrate_v4.sql` (또는 `.txt`)을 실행합니다.

기존 데이터를 지우지 않고 아래를 더합니다. **v1·v2·v3 어느 DB에서 실행해도 됩니다.**

1. (v2가 안 된 DB라면) `lots`·`tx_logs`의 대분류·단가·금액 열과 축종 표기 정리
2. (v3가 안 된 DB라면) 거래구분·정산상태·세금계산서 열과 기본값 채우기(화면은 쓰지 않음)
3. 완제품 표 `fp_products` · `fp_logs` 추가 (초기 데이터 없음)
4. 회계 표 `acc_vouchers` · `acc_payments` · `acc_expenses` 추가
5. 완제품·회계 저장 함수, 권한(RLS), 실시간 등록 추가
6. `lots`·`tx_logs`의 기존 행과 값은 **바뀌지 않습니다**

> 실행 전에 Supabase → Database → Backups 에서 백업을 한 번 받아 두세요.
> 두 스크립트 모두 여러 번 실행해도 안전합니다(if not exists / create or replace).

## 설치 2단계 — 계정 만들기

이 프로젝트는 **이메일 확인(Confirm email)이 켜져 있어** 앱에서 만든 계정은 메일 확인을 눌러야 로그인됩니다.
회사 내부용으로 바로 쓰시려면 둘 중 하나를 고르세요.

- **A. 이메일 확인 끄기 (권장)**
  Supabase → **Authentication** → **Sign In / Providers** → **Email** → `Confirm email` 끄고 저장.
- **B. 관리자가 계정을 직접 추가**
  Supabase → **Authentication** → **Users** → **Add user** → 이메일·비밀번호 입력, `Auto Confirm User` 체크.

작업자 이름은 계정을 만들 때 넣은 이름(`User Metadata → name`)으로 이력에 표시되고,
없으면 이메일 앞부분이 표시됩니다.

## 설치 3단계 — 웹에 올리기

**GitHub Pages (무료, 간단)**

## 쓰는 법

### 🥩 원료육

| 하고 싶은 일 | 방법 |
|---|---|
| 입고 | `📥 입고` → 창고·대분류·제품명·입고일·소비기한·중량·입고단가 입력 → 저장 |
| 해동 | 냉동고 재고표의 `해동` → 중량 입력 → 저장 |
| 재냉동(생산 취소) | 냉장고 재고표의 `재냉동` → 중량·사유 입력 → 저장 |
| 출고 | 재고표의 `출고` → 출고처 구분(현장/업체/택배/기타) → 상세·출고단가 입력 |
| 잘못 입력 취소 | `📋 입출고 내역`의 `취소` — 재고가 입력 전으로 돌아갑니다 |
| 기간으로 보기 | `📅 기간선택`(2개월 달력) 또는 빠른 버튼 + `🔍 검색` |
| 엑셀로 받기 | 오른쪽 위 `⬇ 냉동고 재고` / `냉장고 재고` / `입출고 내역` |

### 📦 완제품

| 하고 싶은 일 | 방법 |
|---|---|
| 새 상품 | `＋ 새 상품 등록` → 코드(자동 채움)·대분류·상품명·**규격**·단위·입고/출고단가·초기재고 |
| 입고 | `📥 입고` 탭 → 상품 선택 → 수량·단가(비우면 상품단가)·소비기한·거래처 → `입고 저장` |
| 출고 | `📤 출고` 탭 → 상품 선택 → 수량·출고단가·거래처 → `출고 저장` |
| 단가 바꾸기 | `💰 단가 관리`에서 `수정` 또는 재고현황의 `단가` |
| 상품 정보 수정 | 재고현황의 `수정` — 이름·규격·단위·단가·거래처 |
| 엑셀 일괄 | `⬇ 양식`으로 받아 채운 뒤 `⬆ 엑셀`로 올리기 (.xlsx/.csv) |
| 잘못 입력 취소 | `📋 입출고 이력`의 `취소` — 재고가 원복됩니다 |

### 💰 회계

| 하고 싶은 일 | 방법 |
|---|---|
| 매출·매입 전표 | `＋ 매출 전표` / `＋ 매입 전표` → 거래처·과세/면세·금액(부가세 자동) |
| 세금계산서 상태 | 전표 줄의 `미발행`/`미수령` 버튼을 누르면 발행완료/수령완료로 바뀝니다 |
| 입출고를 전표로 | `⚡ 입출고 일괄 반영` → 기간 고르고 체크 → `선택 반영` |
| 수금·지급 | 거래처 원장의 `수금`/`지급` 또는 위의 `＋ 수금(입금)` |
| 수금 내역 확인·삭제 | 거래처 원장의 `내역` |
| 경비·수입 | `＋ 경비·수입` (또는 통장·카드 엑셀 업로드) |
| 월별 손익 | `📊 월별 손익` 탭 → `⬇ 엑셀` |

## DB 구조 (v4)

| 표 | 쓰는 곳 | 내용 |
|---|---|---|
| `lots` | 원료육 | 로트(대분류·제품·업체·입고일·소비기한·냉동/냉장 수량·기준단가) |
| `tx_logs` | 원료육 | 입고·해동·재냉동·출고 이력 |
| `fp_products` | 완제품 | 상품코드·대분류·상품명·**규격**·단위·재고·입고단가·출고단가·유통기한 |
| `fp_logs` | 완제품 | 입출고 이력 |
| `acc_vouchers` | 회계 | 매입·매출 전표(과세/면세·공급가·부가세·세금계산서 상태) |
| `acc_payments` | 회계 | 거래처 수금(입금)·지급(출금) |
| `acc_expenses` | 회계 | 일반 경비·수입 |

- 모든 표는 **로그인한 사람만** 읽고 쓸 수 있습니다(RLS + GRANT). 비로그인(anon)은 완전 차단.
- 입출고 저장·취소·재고 계산은 DB 함수가 한 트랜잭션에서 처리해 PC·폰 동시 입력에도 어긋나지 않습니다.
- 표가 바뀌면 다른 기기 화면도 실시간으로 갱신됩니다(웹소켓, 막히면 1분 자동 새로고침).

## 문제가 생기면
