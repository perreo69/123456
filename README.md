# 미르스타푸드 ERP — 입출고 · 재고 · 구매 · 판매 · 생산원가 · 회계

냉동고·냉장고 원료육 재고, 완제품·부자재 재고와 입출고, 매입·매출·수금·지급,
현장 투입 생산원가까지 **하나의 통합 메뉴**에서 이어 쓰는 웹앱입니다.
Supabase 로그인으로 들어가고 데이터는 Supabase에 저장되므로 PC·폰 어디서 열어도 같은 내용이 보입니다.

- **6대 메뉴**: `1. 입출고관리` · `2. 재고관리` · `3. 구매관리` · `4. 판매관리` · `5. 생산·원가관리` · `6. 회계·손익`
  (상단의 원료육/완제품/회계 3모드 탭은 없앴습니다)

  `↔ 열 너비 초기화`로 되돌립니다.

## 1. 🥩 원료육 ERP

기존 원료육 ERP 기능을 그대로 두고, 14가지 요청을 반영했습니다. (원료육 화면에는 회계 항목이 없습니다)

- 모드: `📥 입고` · `🧊→❄️ 해동` · `❄️→🧊 재냉동` · `📤 출고(현장/업체/택배/기타)`
- **대분류 없음**: 입력칸·필터·표·CSV 어디에도 나오지 않습니다. 분류는 `육류`(돈육/우육/계육/양육) 하나만 씁니다.
- 표: 냉동고 재고 · 냉장고 재고 · 입출고 내역 · **📈 단가 변동**
- **`📈 단가 변동` 탭**: `tx_logs`의 입고 이력(단가>0)을 품목별로 묶어
  `제품명 · 육류 · 최근 업체 · 직전 단가 · 최근 단가 · 변동액(원/kg) · 변동률(%) · 최근 입고일 · 입고 횟수`
  를 보여줍니다. 기본 정렬은 **변동률이 큰 순**이고, 다른 표와 똑같이 머리글 `▾` 정렬·필터와
  열 너비 드래그를 씁니다. 입고가 2번 이상인 품목만 나옵니다.
- **입력 즉시 등락률 배지**: 입고 폼에서 품목명 + 입고단가를 넣으면 직전 입고단가와 비교해
  **±5% 이상이면 `▲ +8.3%`(빨간) / `▼ -5.0%`(파란)** 배지가 입고단가 칸에 바로 붙습니다.
  (30% 이상 급변은 기존처럼 오타 경고도 함께 뜹니다)
- **머리글 화살표 하나(`▾`)** — 누르면 팝오버 맨 위에 `↑ 오름차순` `↓ 내림차순`, 그 아래에 값 체크박스 필터.
  정렬 중이면 화살표가 `▲/▼` 로 바뀝니다.
- **기간 바**: `📅 기간선택`(2개월 달력) + 날짜칸 + `🔍 검색` + `초기화` 만 있습니다.
- **`작업 ▾` 메뉴**: 표 각 행의 작업 열에 버튼 하나. 누르면 `해동`(냉동고) 또는 `재냉동`(냉장고) · `출고` · `수정`,
  입출고 내역은 `수정` · `취소`. 작업 열 폭이 좁아졌습니다.
- **입출고 내역 구분 6종**: `입고` · `출고`(업체) · `해동` · `현장` · `택배` · `기타`
  - 업체 출고는 `출고`, 업체명은 **비고**에 적힙니다.
  - 택배는 `택배`, 수령처·운송장은 **비고**에 적힙니다.
  - 현장 출고는 `현장`, 생산품목은 **생산품목** 열에 적힙니다.
  - 재냉동은 `기타`로 묶고, 사유는 **비고**에 적힙니다.
- **`생산품목` · `비고` 열 분리**: 해동할 때 적은 생산품명이 생산품목 칸에 그대로 들어갑니다.
  (`냉동 -125.4 / 냉장 +125.4` 같은 자동 문구는 넣지 않습니다)
- `브랜드` 열, `입고단가(원/kg)`·`출고단가(원/kg)` 분리 표시, 사방넷/경리나라 양식 다운로드

### 📷 입고 사진 대기함

- 입고 화면의 **`📷 입고 사진 업로드`** — 로그인한 사람이면 **누구나** 전표 사진을 올립니다.
  사진은 올리는 기기에서 가장 긴 변 1280px JPEG로 줄여서 저장합니다(휴대폰으로 바로 찍는 것도 됩니다).
- 새 사진이 올라오면 상단 **`📷 입고대기 N`** 배지와 알림 토스트·알림음(브라우저 알림은 허용한 경우)으로 알려줍니다.
  실시간 연결이 안 되는 환경에서도 20초마다 새로 확인합니다.
- `📷 입고대기`를 누르면 **대기함**에 사진이 썸네일로 쌓입니다. 사진을 눌러 크게 보고,
  **`입고 폼으로 불러오기`** 를 누르면 사진을 작게 띄워 둔 채 왼쪽 입고 폼을 채울 수 있습니다.
- 내용을 확인하고 **`입고 저장`** 을 누르면 입고가 등록되면서 그 사진이 **처리 완료(registered)** 로 바뀌어 대기함에서 빠집니다.
  아직 등록 전인 사진은 대기함에서 지울 수 있습니다.

## 2. 📦 완제품 ERP

- **요약 카드**: 완제품 총재고 · 보유 품목 · 총 재고금액(입고단가 기준) · 오늘 입출고 · 단가 미입력
- **대분류 필터**: `전체` `완제품` `소스` `부재료` `향신료` `야채류` + `＋ 직접입력`(직접 만든 분류는 저장됨)
- **왼쪽 입력**: `📥 입고` / `📤 출고` 탭, `＋ 새 상품 등록`, 상품코드·상품명으로 찾기
  - **`규격`**·`단위`·`입고단가`·`출고단가`를 상품마다 관리하고, 입출고 할 때 그대로 따라갑니다.
  - 출고는 재고보다 많으면 막고, 필요하면 `재고보다 많이 출고 허용`을 켜 마이너스 재고로 기록합니다.
- **오른쪽 탭 2개**: `📦 재고현황` · `📋 입출고 이력` (v6에서 `단가 관리` 탭을 없앴습니다)
  - 재고현황: 대분류 · 상품코드 · 상품명 · **규격** · 단위 · 재고 · 입고단가 · 출고단가 · **재고금액** · 유통기한
  - 이력: 날짜 · 구분 · 코드 · 상품명 · 규격 · 단위 · 수량 · 입고/출고단가 · 금액 · 소비기한 · 거래처·비고 · 작업자
- **재고현황 `작업 ▾`**: 행마다 버튼 하나로 `💰 상품·단가 수정` · `✏️ 상품 정보 수정`을 바로 엽니다.
- **입고구분 `🏭 자체생산` / `🏢 외부매입`**
  - `🏭 자체생산`: 거래처가 `자체생산`으로 잡히고 비고에 `[자체생산]`이 붙습니다.
    왼쪽 폼에 최근 7일 **원료육 현장 투입(생산 투입) 건수·kg·금액** 참고 안내가 뜰니다.
  - `🏢 외부매입`: 평소처럼 매입처를 적습니다.
  - 회계 `⚡ 입출고 일괄 반영`에서는 `자체생산` 입고를 **자동 제외**해 원가·매입 이중집계를 막습니다.
- **엑셀 (`📊 엑셀 ▾`)**
  - `⬇ 완제품 재고 (.xlsx)` · `⬇ 입출고 이력 (.xlsx)`
  - `⬇ 입출고 양식 받기` · `⬆ 입출고 엑셀 올리기` — `.xlsx` / `.csv` 를 그대로 올립니다. 코드가 비면 상품명으로 찾습니다.
  - `⬇ 단가표 양식 받기` · `⬆ 단가표 엑셀 올리기` — 상품코드·상품명·**규격**·단위·입고단가·출고단가
- 외부 라이브러리(CDN) 없이 **순수 JS**로 엑셀을 읽고 씁니다(압축 해제까지 직접 구현).
  인터넷이 막힌 환경에서도 업로드·다운로드가 됩니다.

## 3. 💰 회계 ERP

원료육·완제품과 분리된 전용 회계 모듈입니다.

- **요약 카드 6개**: 총 미수금 · 총 미지급금 ·
  세금계산서 미발행/미수령 · 이번 달 매출 · 이번 달 매입·경비 · 예상 순이익
- **탭 4개**
  1. `📋 매입·매출 전표`
     - 직접 추가·수정·삭제, **면세/과세(부가세 10%) 자동 계산**, `부가세 포함 금액`으로 입력하면 거꾸로 계산
     - **세금계산서 발행/수령 상태** 버튼 한 번으로 토글
     - **`⚡ 입출고 일괄 반영`**: 기간 안의 원료육 입고·업체출고, 완제품 입출고 중
       금액이 있는 건을 체크해 **클릭 한 번으로 전표로** 넘깁니다.
       원료육은 면세, 완제품은 과세가 기본(전부 면세/과세로 바꿀 수 있음). 같은 이력은 두 번 들어가지 않습니다.
       **🏭 자체생산 완제품 입고는 사내 생산 이동이라 목록에서 자동 제외**합니다(이중집계 방지).
  2. `🏢 거래처별 원장`
     - 거래처별 총 매출·총 수금·**남은 미수금**, 총 매입·총 지급·**남은 미지급금**, 미수금−미지급금
     - `수금`·`지급`을 등록하면 잔액이 바로 차감되고, `내역`에서 그동안의 입금·출금을 보고 지울 수 있습니다.
  3. `💳 일반 경비·자금`
     - 택배비·부자재·전기세·임대료·급여·식대·차량유지비 등 재고 외 지출/수입
     - 간편 입력 또는 **통장·카드 엑셀 업로드**(날짜·적요·거래처·출금·입금 → 경비/수입 자동 구분)
  4. `📊 월별 손익`
     - 월별 매출 − 매입원가 − 일반경비 = **순이익** 표와 합계, 엑셀 다운로드
- 회계 표에도 **열 너비 드래그 + 2개월 달력 + 검색 버튼**이 똑같이 적용됩니다.
- 회계 표 오른쪽 `📊 엑셀 ▾`: `⬇ 현재 표 엑셀` · `⬆ 통장·카드 엑셀 올리기`
- 순이익은 부가세를 빼고 **공급가액** 기준으로 계산합니다.

  (필요 없으면 나중에 `drop table` 로 지우면 됩니다).
- `truncate ... cascade` 를 쓰지 않습니다. `inbound_photos` 가 `lots` 를 참조하고 있어 cascade 로 지우면
  **입고 사진까지 사라지기** 때문입니다. 사진은 그대로 남고, 사진에 걸린 로트 연결(`lot_id`)만 비워집니다.
- 회계 `⚡ 입출고 일괄 반영`으로 만든 전표는 예전 이력 번호(`source_id`)를 가리킵니다.
  번호가 1번부터 다시 매겨지므로, 그런 전표가 있으면 실행 뒤 금액·거래처를 한 번 확인하세요.

## 설치 2단계 — 계정 만들기

이 프로젝트는 **이메일 확인(Confirm email)이 켜져 있어** 앱에서 만든 계정은 메일 확인을 눌러야 로그인됩니다.
회사 내부용으로 바로 쓰시려면 둘 중 하나를 고르세요.

- **A. 이메일 확인 끄기 (권장)**
  Supabase → **Authentication** → **Sign In / Providers** → **Email** → `Confirm email` 끄고 저장.
- **B. 관리자가 계정을 직접 추가**
  Supabase → **Authentication** → **Users** → **Add user** → 이메일·비밀번호 입력, `Auto Confirm User` 체크.

작업자 이름은 계정을 만들 때 넣은 이름(`User Metadata → name`)으로 이력에 표시되고,
없으면 이메일 앞부분이 표시됩니다.

## 설치 3단계 — 웹에 올리기

**GitHub Pages (무료, 간단)**

## DB 구조 (v5 그대로 — v7·v8은 SQL 변경 없음)

v7은 화면(index.html · style.css · app.js)만 바꿔으며, **v5 DB 스키마/SQL을 그대로 씁니다.**
브랜드 영문 변환(`supabase_brand_en_update.sql`)은 **선택**이고, 데이터 값만 바꾸는 스크립트입니다.
완제품 자체생산 구분은 새 열 없이 `fp_logs.partner = '자체생산'`과 `note`의 `[자체생산]` 표시로 처리합니다.

| 표 | 쓰는 곳 | 내용 |
|---|---|---|
| `lots` | 원료육 | 로트(대분류·제품·업체·입고일·소비기한·냉동/냉장 수량·기준단가) |
| `tx_logs` | 원료육 | 입고·해동·재냉동·출고 이력 |
| `fp_products` | 완제품 | 상품코드·대분류·상품명·**규격**·단위·재고·입고단가·출고단가·유통기한 |
| `fp_logs` | 완제품 | 입출고 이력 |
| `acc_vouchers` | 회계 | 매입·매출 전표(과세/면세·공급가·부가세·세금계산서 상태) |
| `acc_payments` | 회계 | 거래처 수금(입금)·지급(출금) |
| `acc_expenses` | 회계 | 일반 경비·수입 |

- 모든 표는 **로그인한 사람만** 읽고 쓸 수 있습니다(RLS + GRANT). 비로그인(anon)은 완전 차단.
- 입출고 저장·취소·재고 계산은 DB 함수가 한 트랜잭션에서 처리해 PC·폰 동시 입력에도 어긋나지 않습니다.
- 표가 바뀌면 다른 기기 화면도 실시간으로 갱신됩니다(웹소켓, 막히면 1분 자동 새로고침).

## 문제가 생기면

- **"DB 표·함수를 찾을 수 없습니다"** → SQL Editor에서 `supabase_setup.sql`(기존 DB는 `supabase_migrate_v5.sql`)을 실행하세요.
- **입고 사진이 안 올라가거나 대기함이 안 보임** → 같은 이유입니다. `supabase_migrate_v5.sql`을 한 번 실행하세요.
- **완제품·회계 화면이 비어 있고 안내가 뜸** → 위 v4 마이그레이션을 아직 실행하지 않은 DB입니다.
- **로그인이 안 됨** → 이메일 확인 설정(위 2단계)을 확인하세요.
